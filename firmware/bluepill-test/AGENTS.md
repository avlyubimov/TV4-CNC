# Blue Pill — только стенд

Наследовать корневой AGENTS.md. Контроллер станка — F407, не F103.
По отчёту владельца OpenOCD 0.12.0/ST-Link V2 видят Cortex-M3 и 64 КиБ Flash;
SWD работает, backup локальный, таблица векторов структурно корректна.
Это не подтверждение работы CAN, таймеров, загрузчика или firmware на станке.

- Не считать доступными 128 КиБ и не писать за подтверждённые 64 КиБ.
- Разрешённое назначение будущего ПО: host/bench протокол, прерывания,
  аппаратные таймеры и эксперименты с recovery без подключённых приводов.
- Реальные CAN ID, bitrate, remap и GPIO не назначать без board/transport decision.
  Трансиверов пока нет; до их получения — host-симуляция.
- Backup, UID/секретные дампы и приватные ключи не коммитить и не прикладывать
  к CI. Сохранить возможность восстановления. Валидная таблица векторов
  не доказывает подлинность заводского ПО или успешный запуск.
- Любой SWD доступ/Flash erase/write/option bytes требует отдельного разрешения;
  наличие ST-Link не является разрешением. PR-01 не добавляет код прошивки.
