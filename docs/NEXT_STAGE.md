# Следующий этап: сборка ESP32-S3

План: получить официальные исходники/пример платы, подтвердить базу конфигурации,
собрать безопасный ESP-IDF target с LVGL 9, разрешить и зафиксировать зависимости.
Затем подготовить адаптер дисплея и касания только по проверенным источникам.

Критерии: настоящий результат idf.py build; сохранённый dependency lock;
записаны версии и точные команды; отсутствие CAN TX/выходов движения;
непроверенные аппаратные зависимости явно блокируют запуск драйверов.
Физическое устройство не прошивается на этом этапе.
