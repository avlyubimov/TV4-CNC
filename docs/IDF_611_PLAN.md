# Проверка ESP-IDF 6.1.1

Ветка fix/esp-idf-6.1.1 отделена от проверенного main (20b8114, ESP-IDF 5.3.2).
План: зафиксировать исходную ошибку; мигрировать I2C LCD/CH422G и RGB DMA API;
собрать headless/rev12 установленным SDK, с конфигурацией Flash 16 MB;
повторить host/рендер/безопасность и сборки 5.3.2; обновить CI и документацию.

Критерии: чистые сборки обоих профилей, точные версии/хеши, проверенные
sdkconfig/partition/image headers, сохранённые логи и результаты тестов.
Параметры RGB, частота PCLK, 400 kHz I2C, интервалы опроса, буферы и архитектура
владельца LVGL сохраняются; производительность железа не заявляется без замеров.
Нет flash/monitor/доступа к USB и проверки устройства. 16 MB — конфигурация
сборки по запросу пользователя, а не результат чтения flash_id.
