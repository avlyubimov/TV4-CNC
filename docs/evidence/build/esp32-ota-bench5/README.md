# Bench.5: сборка и публикация

Source `0dbc1e919bc671554a005dac1896562c6554fe26`, main после merge владельцем
[PR #91](https://github.com/avlyubimov/TV4-CNC/pull/91).
[Prerelease v0.1.0-bench.5](https://github.com/avlyubimov/TV4-CNC/releases/tag/v0.1.0-bench.5)
опубликован по отдельному разрешению на точные source/tag и 12 файлов.
Признаками latest/stable он не отмечен. Этот отчёт фиксирует выполненные
действия; разрешения на новый выпуск или аппаратный сеанс он не даёт.

## Сборки с утверждёнными настройками

На каждом закреплённом SDK 5.3.2/6.1.1 собраны два кандидата `.5` и принимающая
`.4` с диагностикой памяти: всего шесть чистых сборок. Пары кандидатов используют
разные пути проекта и публичного контекста, compiler cache выключен. Все байты
BIN/ELF/bootloader/table и фактические конфигурации совпали внутри каждой пары.
Для принимающей `.4` выполнена одна сборка на SDK; независимая пара не заявляется.

| SDK | App `.5`, байт | SHA-256 app |
|---|---:|---|
| 5.3.2 | 1553712 | `ef648c65e0a82262a87b00d82ab055c7ee98e61671358b78a74adaf2d1d77a4e` |
| 6.1.1 | 1600720 | `d6a59a78595541d0fa45fc327dd2ba0a6e0fb5006303c0f5921c4669cd49347a` |

Точные image pins, времена, app descriptors и hashes четырёх артефактов —
[reproducibility.json](reproducibility.json), скачанный обратно из релиза без
изменения байтов. Его флаги публикации и доступа к hardware отражают момент
сборки, до публикации и аппаратного сеанса. Сравнение выполнено без нормализации или перезаписи ELF;
дата и время компиляции в app descriptor нулевые. Проверка даты TLS-сертификата
включена. Равенство между SDK, перенос toolchain/host OS и производительность
этой проверкой не подтверждаются.

В фактических ELF проверены прежний публичный ключ и утверждённые константы
времени и ресурсов. Контексты `.4→.5` — новые локальные стендовые файлы до
27 ноября 2026, 08:00 Asia/Almaty. Старые контексты и bench.2/.3/.4 не менялись.
Пороги: internal free/largest 64/32 КиБ, PSRAM free/largest 1 МиБ/128 КиБ,
остаток стека worker ≥3072 из 12288 байт; unauthenticated SNTP, возраст anchor
≤10 минут, skew ≤5 секунд. Это начальные инженерные ограничения стенда;
производственный бюджет памяти ещё не принят.

## Подпись и публикация

Использован существующий authoring/verifier для обоих SDK. Проверены подпись
исходных байтов manifest, SHA-256, размер и descriptor приложения, ELF digest,
source/SemVer/hardware/layout и подписанный `installable=true`. Реальный C
manifest verifier и full-image stream tests прошли для обоих SDK; изменённый
manifest и неверный ключ отвергнуты. Криптография и HTTPS stack сохранены.

Опубликован app SDK 6.1.1; резервная сборка SDK 5.3.2 хранится локально. Все 12
файлов скачаны обратно через HTTPS с проверкой сертификата, размеры и SHA-256
совпали; подпись и полный BIN повторно проверены.
[Результат и полный inventory](publication.json).
SHA-256 файла `release-checksums.sha256`:
`00e338b0a13d7dfb786bc4d15c603bd20cffa4b1e751ff8d9e5e6196b9e7d650`.
Manifest подписывает метаданные приложения; остальные evidence/inventory не
являются подписанным подтверждением CI или происхождения исходников. Локальные
сборки не выдаются за бинарники, полученные в CI.

Ключи, контексты, Flash/NVS, сырой UART и STM32 images не опубликованы.
Приложены MIT и прежние тексты third-party notices; зависимости и лицензии
сохранены. В app OTA assets нет bootloader, таблицы разделов или otadata.

## Программные проверки и границы

[CI тега](ci.json): 17/17 PASS. Финальные ветка и PR #91 — 34/34, main — 17/17.
291 host и 291 ASan/UBSan/LSan suites, реальные LVGL 9.2.2 renders и матрица обоих
SDK PASS. [Сводка](results.json).
[Metadata oracle](metadata-oracle.json) сверяет seq3/seq4/CRC/layout с официальной
SDK-утилитой через fake file target, без подключения serial.

Локальная стендовая процедура прошла [31 RAM-Flash/fake-serial case](procedure-tests.txt)
и [те же 31 при Python `-O`](procedure-tests-optimized.txt): отказ по touch до
сети, две копии до записи, точные границы записи, SNTP/cleanup, запрет раннего
сброса, полное окно self-test, отказ при повреждении app/PENDING metadata,
ограниченные deadlines и восстановление. Преобразованные прежние приватные
UART-журналы использованы только как программные fixtures. Они не доказывают
работу нового app на плате и не включены в repository CI.

[Аппаратная приёмка bench.5 не пройдена](../../hardware/2026-11-25-esp32-bench5/README.md):
сеть и INSTALL PASS, после перезапуска RTC watchdog; исходный bench.4 восстановлен.
Потеря RF/AP/питания, production policy/бюджет/поиск версий, runtime 5.3.2 и
физические FPS/touch latency остаются открытыми. Возраст диагностической touch
sample не равен задержке от физического касания до изображения.
