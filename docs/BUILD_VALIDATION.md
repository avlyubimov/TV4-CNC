# Сборка прошивки ESP32-S3

16 ноября 2026. Только разработка, компиляция и тесты на компьютере.
Подключение к плате и операции с flash не выполнялись. Пользователь самостоятельно
делает backup; запуск на устройстве отложен до его сообщения.

## Выполнено
- Полный исполняемый цикл LVGL 9 в app_main, единственный владелец UI.
- Безопасный профиль по умолчанию: UI работает с виртуальным дисплеем,
  без инициализации GPIO, I²C, RGB, касания и CAN.
- Отдельный выключенный по умолчанию адаптер RGB/GT911/CH422G для Rev 1.2.
  Конфигурация сверена с официальной схемой и исходниками; работа на железе
  не подтверждена. USB_SEL остаётся в USB, SD deselected, CAN не запускается.
- GT911 опрашивается отдельной задачей, в UI передаётся снимок через очередь.
  Устаревшее касание отпускается, отсутствие корректных данных 500 мс защёлкивает
  ошибку. Подсветка включается после первого кадра.
- Исключены повторные выделения памяти и перерисовки неизменившихся показаний.
- Получен настоящий dependencies.lock с хешами компонентов.
- Добавлены рабочая библиотека инструмента с черновиком/клавиатурой и
  разделы Диагностика/Журнал, инъекции отказов макета,
  причины ошибок и ограниченная история на 32 записи; детали в SOFTWARE_STAGE_002.md.

## Воспроизводимость
ESP-IDF 5.3.2, xtensa-esp-elf GCC 13.2.0; LVGL 9.2.2;
GT911 1.1.3; базовый esp_lcd_touch 1.2.1.
Docker image:
`espressif/idf@sha256:5b8f58d9d9caa45b689a31a0b6a0cc53b84594e0ba5fdd8d28eeef7d6123242a`.

Из корня проекта выполнены:

```sh
./tools/build_idf.sh headless
./tools/build_idf.sh rev12
cmake --build work/build-ui -j 4
ctest --test-dir work/build-ui --output-on-failure
```

Последние две команды запускались из рабочей папки разработки, где build-ui
настроен на исходники проекта и официальный LVGL commit
7f07a129e8d77f4984fff8e623fd5be18ff42e74. Команды создания собственного build-ui
приведены в firmware/esp32-hmi/README.md.

Обе команды ESP-IDF завершились `Project build complete.`.
Host CTest: **3/3 успешно** — ядро, рендер 32-bit и рендер RGB565.
Проверены локализация/шрифт, границы текста/кнопок трёх экранов, состояния,
инъекции ошибок касания/дисплея, переполнение журнала и UI-очереди,
перелистывание страниц и отсутствие автозапуска после ACK, редактор/клавиатура
инструмента, валидация/отмена и выбор активного без изменения координат. Подтверждено значение
TV4_BOARD_REV12: выключено в headless, включено в rev12.

## Ограничения
Один RGB framebuffer допускает tearing. На устройстве не проверены PCLK,
ориентация касания, реальная память, перезапуски/обрыв питания и поведение
при аппаратных сбоях. FPS, heap и физическая задержка касания не измерялись.
Ни одного выхода движения или CAN TX в приложении нет. Экранный STOP не
заменяет независимый аварийный останов станка.

Диагностика/журнал: SOFTWARE_STAGE_002.md. Библиотека инструмента: SOFTWARE_STAGE_003.md.
Новый пример Waveshare использует esp_lvgl_adapter 0.5.2 с требованием
ESP-IDF >=5.5; наш адаптер использует непосредственно RGB API ESP-IDF 5.3.2.
Подробности и источники: docs/BOARD_ADAPTER.md.
Журналы компиляции сохранены в docs/evidence/build/. Напечатанные сборщиком
команды flash не исполнялись и не являются разрешением на запись платы.
