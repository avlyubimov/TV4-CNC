# Реализация M1: текущее состояние

## Завершено программно
- Русский LVGL 9 интерфейс по пользовательскому референсу, 800×480,
  ограниченная очередь, симуляция X/Z и инертный транспорт.
- Локализация и шрифты с кириллицей, тесты состояний, отказов и компоновки.
- Цикл LVGL в ESP-IDF, headless профиль без периферии и отдельный адаптер
  дисплея/касания Rev 1.2, по умолчанию выключенный.
- Реальные сборки ESP-IDF 6.1.1 (Ubuntu) и 5.3.2 (резерв) обоих профилей,
  Flash 16 MB, два точных lock-файла и локальный/Docker скрипт.
- Host-тесты 32-bit и RGB565; логирование кадров/heap/задержки событий.
- Библиотека четырёх инструментов с валидацией, черновиком и клавиатурой.
- Рабочая навигация Главная/Инструмент/Диагностика/Журнал, причины ошибок и кольцевой
  журнал RAM на 32 записи с четырьмя страницами. Отдельный ручной запуск
  новой симуляции после ACK; история при этом сохраняется.

Подробные результаты: [BUILD_VALIDATION.md](BUILD_VALIDATION.md).
Адаптер: [BOARD_ADAPTER.md](BOARD_ADAPTER.md).
Текущий состав интерфейса: [UI_REFERENCE.md](UI_REFERENCE.md).

## До завершения испытаний
Заводской backup 16 МиБ завершён, размер и SHA-256 подтверждены:
[BACKUP_STATUS.md](BACKUP_STATUS.md). Нужны физические проверки PSRAM,
дисплея, касания, восстановления и измерения производительности HMI.
В задаче SDK 6.1.1 устройство не подключалось и не прошивалось.

Программа/Параметры и часть органов управления остаются заглушками.
Работают Главная/Инструмент/Диагностика/Журнал, подробности в SOFTWARE_STAGE_002.md.
Машинные/рабочие системы координат, CAN bench, motion planner и обработка
станка — следующие отдельные этапы; в текущем коде физических команд нет.
Условный диапазон симуляции ±1000 мм не является размером станка.

## Откат
Аппаратура не прошивалась. Предыдущие исходники сохранены в архивах этапов,
заводской каркас — в TV4-CNC-original.zip. Удаление новых файлов/восстановление
исходников не затрагивает механическую или электрическую часть станка.
В исходной папке инициализирован Git (main) для публикации на GitHub.
Бэкапы flash, окружение и результаты сборок исключены из репозитория.
