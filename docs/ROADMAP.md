# Roadmap

- **M0** Documentation, BOM, board verification, factory firmware backup instructions.
- **M1** ESP32-S3 LVGL 9 simulation dashboard, build, tests and responsiveness measurements.
- **M2** CAN protocol bench tests with Blue Pill and transceiver; fault injection; no machine outputs.
- **M3** STM32F407 firmware skeleton, deterministic timer-based motion bench testing without lathe attachment.
- **M4** Safety wiring review, interlocks, homing, limits, individual axis commissioning with measured data.
- **M5** Lathe spindle feedback, threading synchronization, reversible manual/CNC integration.
- **M6** Optional spindle servo, indexing/C-axis and removable milling attachment after mechanical validation.

Each milestone needs evidence and explicit authorization before energizing motion hardware.
